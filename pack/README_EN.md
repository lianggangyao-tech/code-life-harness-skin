# Code Life (代码人生) · Skin for DeepSeek Harness

A code-world look for DeepSeek Harness: three themes, a custom four-column layout, a home page with greetings, an optional code-rain background, and Matrix-style scramble-and-decode status text while the model is working.
**Unofficial — not affiliated with DeepSeek.** Installs through Harness's official plugin mechanism, never modifies the app bundle, and can be removed at any time.

- Requires macOS and DeepSeek Harness **0.2.1-rc.3** (other versions may partially break; you can switch back to the original layout from the Skin page).
- Free and open source (MIT). One-line install: `curl -fsSL https://raw.githubusercontent.com/lianggangyao-tech/code-life-harness-skin/main/get.sh | bash`
- Or: unzip → double-click `install.command` (right-click → Open the first time) → quit Harness (⌘Q) and reopen.
- Manual install (any OS): Harness → Plugins → Add plugin → Local directory → path of the `plugin` folder.
- Uninstall: double-click `uninstall.command`, or remove `dsh-skin-code-life` on the Plugins page.
- Privacy: runs locally only; no network calls, no data collection.
